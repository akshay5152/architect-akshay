# Architect Akshay

A modern, high-performance portfolio/architectural showcase website built with **Next.js 16** and advanced animations using **GSAP** and **Lenis**. 

🌐 **Live Demo**: [https://architect-akshay.vercel.app](https://architect-akshay.vercel.app)

## 🎯 Overview

Architect Akshay is a sleek, interactive web platform designed to showcase architectural projects and services. The application features smooth scrolling, stunning animations, and a modern design philosophy to create an immersive user experience.

## ✨ Key Features

- **Smooth Scrolling**: Enhanced scroll experience with Lenis library
- **Advanced Animations**: GSAP-powered animations for engaging interactions
- **Responsive Design**: Mobile-first approach with modern CSS techniques
- **Next.js 16**: Latest Next.js framework with optimized performance
- **TypeScript**: Fully typed codebase for better development experience
- **Vercel Deployment**: Seamless deployment and hosting

## 🛠️ Tech Stack

| Component | Technology |
|-----------|------------|
| **Framework** | [Next.js 16](https://nextjs.org) |
| **Runtime** | [Node.js](https://nodejs.org/) |
| **Animations** | [GSAP 3.15](https://gsap.com/) |
| **Smooth Scroll** | [Lenis 1.3](https://lenis.studiofreight.com/) |
| **Language** | TypeScript 5 |
| **Styling** | CSS Modules / Tailwind CSS |
| **Deployment** | [Vercel](https://vercel.com) |

## 🚀 Getting Started

### Prerequisites

- **Node.js**: v18.x or higher
- **npm** or **yarn** or **pnpm**

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/akshay5152/architect-akshay.git
   cd architect-akshay
   ```

2. Install dependencies:
   ```bash
   npm install
   # or
   yarn install
   # or
   pnpm install
   ```

### Development

Start the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

### Building for Production

```bash
npm run build
npm run start
```
